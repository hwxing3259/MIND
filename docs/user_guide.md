# User guide

This guide covers the two questions most users ask when first reaching for
MIND:

1. **How do I format my own data?**
2. **Which hyperparameters should I tune, and to what?**

It complements the autogenerated [API reference](api.rst).

## 1. Input format

`MIND.MIND` accepts a single argument, `data_dict`, which is a Python
dictionary mapping a modality name to a `pandas.DataFrame`. The DataFrames
must satisfy:

| Property | Requirement |
|---|---|
| **Row count** | Identical across all modalities. |
| **Row index** | Aligned across modalities — row *i* of `RNA` and row *i* of `methyl` must refer to the same patient. |
| **Missingness** | Patients missing from a modality are encoded as a row of all-NaN. Partially-observed rows are not supported and will raise `ValueError`. |
| **Dtype** | Numeric (float). |
| **Scale** | Approximately z-scored (zero mean, unit variance per feature) is strongly recommended — MIND assumes a standard-Normal prior on the latent space. |

Example:

```python
import pandas as pd
from sklearn.preprocessing import StandardScaler

rna = pd.read_csv("rna.csv", index_col=0)
methyl = pd.read_csv("methyl.csv", index_col=0)

# Align indices: outer-join, then set rows that are missing in one
# modality to NaN.
all_patients = rna.index.union(methyl.index)
rna = rna.reindex(all_patients)
methyl = methyl.reindex(all_patients)

# Z-score per modality, ignoring NaNs.
def zscore(df):
    obs = ~df.isna().all(axis=1)
    arr = df.values.copy()
    arr[obs] = StandardScaler().fit_transform(arr[obs])
    return pd.DataFrame(arr, index=df.index, columns=df.columns)

rna = zscore(rna)
methyl = zscore(methyl)

data_dict = {"RNA": rna, "methyl": methyl}
```

The package validates the dictionary structure at construction time
(`MIND._validation.validate_data_dict`) — common mistakes raise descriptive
errors immediately rather than producing silent NaN losses later.

## 2. Hyperparameters

| Argument | Default | What it controls | When to tune |
|---|---|---|---|
| `emb_dim` | 128 | Latent embedding dimensionality. | Set to 16–32 for visualisation; 64–128 for downstream prediction with large datasets. |
| `lr` (passed to `my_train`) | 1e-3 | Adam learning rate. | Lower (1e-4) if loss oscillates; higher rarely helps. |
| `n_epoch` (passed to `my_train`) | 2000 | Number of optimisation epochs. | Watch the loss curve — most datasets plateau by 1k–3k epochs. |
| `alpha` | 5e-2 | Weight of the modality-alignment penalty (pull per-modality embeddings of the same patient together). | Increase (0.1–1.0) when modalities give wildly different embeddings; decrease (1e-3) when you want each modality to retain idiosyncratic signal. |
| `beta` | 1.0 | Strength of the t-SNE neighbourhood-preservation term. | Rarely changed. Lower it (0.1) if the embedding looks over-clustered. |
| `perp` | 30 | Perplexity for the per-modality nearest-neighbour graph. Same role as t-SNE perplexity. | Pass a list to use a different value per modality. Lower (10) for smaller datasets (<200 patients). |
| `batch_size` (in `my_train`) | `None` | Mini-batch size. `None` means full-batch (the paper default). | Set to e.g. 256 only for very large patient counts where full-batch training exhausts memory. |
| `device` | `'cpu'` | PyTorch device string. | `'cuda'` if you have a GPU. |

**Suggested workflow for a new dataset:**

1. Verify input format by constructing the model — validation errors will
   point at any structural problems.
2. Train for ~100 epochs at the defaults to make sure the loss decreases.
3. Train for the full 2000 epochs.
4. Plot `get_embedding()[0]` (after PCA or TSNE) and inspect cluster
   structure. If embeddings are degenerate, lower `alpha` and re-train.

## 3. Outputs

`get_embedding()` returns a tuple `(z_mean, z_log_std)` of shape
`(n_patients, emb_dim)`. For most downstream tasks `z_mean` is what you
want; `z_log_std` quantifies per-patient posterior uncertainty.

`predict()` returns a list of per-modality reconstruction tensors. For
patients originally missing in a modality, this is the model's *prediction*
of what their values would have been.

## 4. Reproducing the paper

```bash
python examples/reproduce_results.py --dataset CCMA
```

The script downloads the data on first run, trains MIND with the paper's
hyperparameters, and writes the embeddings + clinical labels to
`./MIND_outputs/`.
