## Third-party code

The package does not vendor any third-party source code. It depends on the
following packages at runtime:

- [PyTorch](https://pytorch.org)
- [openTSNE](https://opentsne.readthedocs.io/)
- [pandas](https://pandas.pydata.org/), [numpy](https://numpy.org/),
  [matplotlib](https://matplotlib.org/), [requests](https://requests.readthedocs.io/)

See `setup.py` / `pyproject.toml` for the pinned version ranges.
